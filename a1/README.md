# PetConnect - Pet Adoption Platform

## Project Overview
PetConnect is a static pet adoption platform developed for COSC2446 Web Programming course at RMIT University. This project demonstrates responsive web design using HTML5, CSS3, JavaScript, and Bootstrap 5.
